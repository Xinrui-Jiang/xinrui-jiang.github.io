**Harbor Trajectory Viewer**

[**Code**](https://github.com/Xinrui-Jiang/harbor-trajectory-viewer)

- A local web app for browsing, auditing and annotating [Harbor](https://harborframework.com) tasks and ATIF agent trajectories. It replays each run as a chat with a file tree that follows the current step, compares two runs side by side from their first divergence point, and supports per-run and per-step annotation with JSONL export.
